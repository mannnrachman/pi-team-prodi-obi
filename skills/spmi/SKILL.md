# SPMI (Sistem Penjaminan Mutu Internal)
Gunakan skill ini untuk melaksanakan siklus PPEPP SPMI di tingkat program studi.

## Steps
1. **P**enetapan standar mutu (acuan SN-Dikti + standar institusi)
2. **P**elaksanaan standar (monitoring ketercapaian)
3. **E**valuasi pelaksanaan standar (audit mutu internal)
4. **P**engendalian pelaksanaan standar (tindakan korektif)
5. **P**eningkatan standar (benchmark dan perbaikan berkelanjutan)

- Kebijakan SPMI
- Manual SPMI
- Standar SPMI
