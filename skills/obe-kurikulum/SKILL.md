# OBE Curriculum Design
Gunakan skill ini ketika merancang atau mengevaluasi kurikulum berbasis Outcome-Based Education.

## Steps
1. Identifikasi profil lulusan dan kebutuhan stakeholders
2. Rumuskan Capaian Pembelajaran Lulusan (CPL/PLO)
3. Petakan CPL ke mata kuliah (CPL-MK matrix)
4. Tentukan CPMK per mata kuliah
5. Rancang metode pembelajaran SCL (Student-Centered Learning)
6. Rancang assessment berbasis CPMK
7. Validasi keselarasan (constructive alignment)

## Referensi
- SN-Dikti (Standar Nasional Pendidikan Tinggi)
- Panduan Kurikulum MBKM
- Buku Panduan OBE dari asosiasi/layanan akreditasi
