# Evaluasi Pencapaian CPMK
Gunakan skill ini untuk mengevaluasi pencapaian Course Learning Outcomes mahasiswa.

## Steps
1. Kumpulkan data assessment (tugas, kuis, UTS, UAS)
2. Petakan setiap komponen penilaian ke CPMK terkait
3. Hitung persentase pencapaian per CPMK per mahasiswa
4. Kelompokkan: tercapai / belum tercapai per CPMK
5. Identifikasi CPMK dengan pencapaian rendah (< 60%)
6. Analisis penyebab (metode pembelajaran, soal, materi)
7. Berikan rekomendasi perbaikan
